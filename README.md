# juggle
Library to generate state change diagrams for juggling patterns of a set height and number of balls.

Note: we are using a slightly different notation for possible states than the psuedo-binary representation that is usually used. Our representation is equivalent.

here are some examples to make the above statement clear:

0101 == 2.4

11001 == 1.2.5

01 == 2

001 == 3

00111 == 3.4.5

etc...
